HM Portfolio Favicon Patch
==========================

How to use:
1. Extract/copy all files from this patch into the ROOT of your hassan-marji-portfolio folder.
2. Double-click APPLY_HM_FAVICON.bat
3. Test index.html locally.
4. If good, push to GitHub:
   git add -A
   git commit -m "Add HM favicon"
   git push origin main

This patch creates these files in your root folder:
- favicon.svg
- favicon-32x32.png
- favicon-16x16.png
- apple-touch-icon.png

It also patches index.html so the browser tab can use the HM logo as the site icon.
